# MartOS

Configuración de mi HP OMEN 16 (Ubuntu 24.04, GNOME): ventiladores, undervolt, GPU, energía,
bash, GNOME y Plymouth. Todo está en un solo repo, con un gestor (`martos`) y documentado.

```bash
./martos estado            # ¿coincide el sistema con el repo?
sudo ./martos sistema      # aplicar sistema/ → /
./martos usuario           # enlazar bash/git al repo
```

📄 **[INFORME.md](INFORME.md)**: qué hace cada archivo, cómo funciona, la revisión de conflictos y cómo restaurar todo tras formatear.
